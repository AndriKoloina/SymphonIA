# SymphonIA - Module OMR (Optical Music Recognition)

Ce module permet d'extraire automatiquement les notes d'une partition (PDF ou image) à l'aide d'un modèle YOLO et d'un traitement géométrique en Python, pour générer une structure JSON exploitable par le front-end.

## Prérequis

- Python 3.8 ou supérieur
- Un environnement virtuel recommandé

## Installation

1. Cloner le dépôt et placer-vous dans le dossier du projet.
2. Installer les dépendances nécessaires :
   ```bash
   pip install -r requirements.txt
