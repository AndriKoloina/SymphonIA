## Note pour les variables indispensables:
pitch : la fréquence
startime : quand la note doit commencer à tomber
duration : la longueur du rectangle qui tombe
x-position : calculée selon la touche du piano correspondante

## Pour la carte du piano : 88 touches

debut (octave 0) : 3 notes
milieu (octave 1 à 7) : 7 octaves complètes de 12 notes
fin (octave 8) : 1 Notes
=> 3 + (7 * 12) + 1 = 88 touches
